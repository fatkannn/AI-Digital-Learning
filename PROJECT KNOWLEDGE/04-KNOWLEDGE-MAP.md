# Knowledge Map

## Big Picture

Digital Technology → Software → Web → APIs → Data → AI → AI Applications
→ Automation → Products

## Digital Foundation

Computer → Operating System → Network → Internet → Server → Database →
Application

## Software Development

Programming → Algorithms → Data Structures → Application Logic → Git →
Testing → Deployment

## AI

AI → Machine Learning → Deep Learning → Neural Networks

Generative AI → LLM → Image Models → Audio Models → Video Models →
Multimodal Models

## LLM Application Stack

User → Interface → Application → Prompt / Instructions → LLM → Tools /
APIs → Data → Database / Vector Database → External Systems

## Knowledge Systems

Documents → Chunking → Embeddings → Vector Database → Retrieval →
Context → LLM → Answer

This is the conceptual foundation of RAG.

## Agent Systems

Goal → Reasoning / Planning → Tool Selection → Tool Execution →
Observation → Iteration → Result

## Automation

Trigger → Workflow → Data → Logic → AI → Action → Output

## Learning Technology

Learner → Content → Activity → Assessment → Data → Analytics → Feedback
→ Intervention

AI can support multiple points in this loop.

## Key Principle

AI is not a separate universe. It is a technology layer that interacts
with software, data, interfaces, APIs, infrastructure, and human
processes.
