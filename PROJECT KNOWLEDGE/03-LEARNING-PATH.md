# Learning Path

## Phase 1 --- Digital Foundations

Learn: - Computer fundamentals - Operating systems - Files and data -
Internet fundamentals - Networking basics - Web fundamentals - Servers
and hosting - Databases - Cloud concepts - Basic cybersecurity

Outcome: understand how digital systems fit together.

## Phase 2 --- Programming Foundations

Learn: - Programming logic - Variables and data types - Conditions -
Loops - Functions - Data structures - Errors and debugging - Basic
Python - Basic JavaScript - Git and GitHub

Outcome: read, modify, and create simple programs.

## Phase 3 --- AI Foundations

Learn: - AI - Machine learning - Deep learning - Neural networks -
Generative AI - LLMs - Multimodal AI - AI limitations

Outcome: understand the AI landscape and terminology.

## Phase 4 --- LLM Foundations

Learn: - Tokens - Context windows - Inference - Prompting - System
instructions - Embeddings - Vector search - Structured output - Tool
calling

Outcome: understand how LLM applications work.

## Phase 5 --- AI Application Development

Learn: - APIs - SDKs - JSON - Authentication - LLM integration -
Databases - RAG - Evaluation - Deployment

Outcome: build small AI applications.

## Phase 6 --- AI Automation

Learn: - Workflow automation - n8n - Webhooks - API integrations - AI
workflows - Agents - MCP

Outcome: automate real processes.

## Phase 7 --- Local AI

Learn: - Local models - Ollama - Model selection - Hardware
requirements - Privacy - Local inference - Quantization concepts

Outcome: understand when local AI makes sense.

## Phase 8 --- Advanced Applied AI

Learn: - Agent architecture - Advanced RAG - Evaluation -
Observability - Security - Cost optimization - Production architecture

Outcome: design robust AI systems.

## Phase 9 --- Portfolio Projects

Build progressively: 1. AI learning assistant 2. AI quiz generator 3.
RAG knowledge assistant 4. AI automation workflow 5. AI-enabled
LMS/e-learning prototype 6. End-to-end AI application

## Learning Rule

Do not advance solely because a topic was read. Advance when the learner
can explain, practice, and apply the concept.
