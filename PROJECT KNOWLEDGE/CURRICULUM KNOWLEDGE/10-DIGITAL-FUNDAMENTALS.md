# Digital Fundamentals

## Core Concepts

### Computer

A computer is a system that processes data using hardware and software.

Key components: - CPU - RAM - Storage - GPU - Motherboard - Input/output
devices

### Operating System

The OS manages hardware and provides services for applications.

Examples: - Windows - Linux - macOS - Android

### Internet

The internet is a network of interconnected networks.

Important concepts: - IP address - DNS - HTTP/HTTPS - TCP/IP - Router -
Client - Server

### Web

A web application commonly involves: - Browser - Frontend - Backend -
Database - APIs

### Server

A server is a computer or software system that provides services or
resources to clients.

### Database

A database stores and manages structured or semi-structured data.

Important concepts: - Tables - Records - Fields - Queries -
Relationships - Indexes

### API

An API is an interface through which software systems communicate.

Typical flow:

Client → Request → API → Server Logic → Database / Service → Response

### Cloud

Cloud computing provides computing resources through remote
infrastructure.

Common categories: - Compute - Storage - Database - Networking - Managed
services

### Git

Git is a version-control system.

Core concepts: - Repository - Commit - Branch - Merge - Pull request -
Remote

## Learning Objective

Understand the architecture behind everyday digital products before
moving deeply into AI.
