# AI Fundamentals

## Artificial Intelligence

AI is a broad field concerned with creating systems capable of
performing tasks that normally require aspects of human intelligence.

Examples: - Perception - Prediction - Classification - Generation -
Planning - Decision support

## Machine Learning

Machine learning uses data and algorithms to learn patterns that can be
used for prediction or decision-making.

Basic idea:

**Data → Training → Model → Prediction**

## Deep Learning

Deep learning uses neural networks with multiple layers to learn complex
representations.

It powers many modern AI systems involving: - Vision - Speech -
Language - Generative models

## Generative AI

Generative AI produces new content such as: - Text - Images - Audio -
Video - Code

## LLM

A Large Language Model is a model trained to process and generate
language.

Conceptually:

Input context → Model inference → Generated output

## AI Limitations

AI systems can: - Hallucinate. - Misinterpret instructions. - Produce
biased outputs. - Fail on edge cases. - Be sensitive to context. -
Generate plausible but incorrect information.

## Important Distinction

AI output is not automatically equivalent to truth.

AI systems must be evaluated according to the task, evidence, context,
and risk.

## Key Questions

When evaluating an AI solution ask: - What problem is being solved? -
Why use AI? - What data is required? - What can go wrong? - How is
output evaluated? - What happens when the model is wrong?
