## Tool Evaluation Rule

For every technology, document: 1. What it is. 2. What problem it
solves. 3. How it works. 4. When to use it. 5. When not to use it. 6.
Strengths. 7. Limitations. 8. Security/privacy considerations. 9. Cost
considerations. 10. Alternatives. 11. A practical experiment.
