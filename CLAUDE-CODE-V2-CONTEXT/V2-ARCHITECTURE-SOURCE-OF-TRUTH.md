# V2 ARCHITECTURE — SOURCE OF TRUTH

## Locked Course Philosophy

> Learn the Digital Learning craft first. Understand AI deeply enough to use it intelligently. Use AI to augment the craft. Keep humans in control of learning decisions.

The primary professional discipline is Digital Learning / E-Learning.

AI has two roles:
1. a separate AI literacy competency
2. an enhancement capability applied to Digital Learning

Target emphasis remains approximately:

- 45% Digital Learning Core
- 25% E-Learning Technology
- 10% AI Fundamentals
- 20% AI-Enhanced Digital Learning

This represents instructional emphasis, NOT a rigid lesson-count formula.

# 2. HUMAN-IN-COMMAND — CROSS-CUTTING

Human-in-Command is NOT a separate phase or module.

It must appear throughout AI Fundamentals and AI Enhancement.

Core workflow:

DEFINE
→ PROMPT
→ GENERATE
→ CRITIQUE
→ VERIFY
→ DECIDE

Human remains responsible for:

- defining the problem
- choosing quality criteria
- evaluating AI output
- verifying evidence
- deciding
- professional accountability

AI output is a draft/assistive artifact, not an authority.

Human-in-the-loop alone is not enough; the curriculum must develop meaningful human agency.

# 3. MICRO-LEARNING ARCHITECTURE

The old 60-minute day model is replaced by micro-learning.

### Target

Approximately **5 minutes per micro-learning**.

This is a target, NOT a rigid timer.

A micro-learning should contain:

- one coherent learning objective
- focused content
- one clear takeaway
- one recall opportunity

Do not split concepts unnaturally to satisfy a numeric duration.

Do not add content merely to increase lesson count.

Final micro-learning count is NOT YET LOCKED.

The current 25-module structure is a consolidated content architecture, not a final day count.

---

# 4. MICRO-LEARNING RECALL QUIZ

Every micro-learning has exactly:

**1 recall / retrieval question**

Purpose:
- retrieval practice
- immediate reinforcement
- recall of the most important idea from that micro-learning

Rules:

- question must test only content explicitly taught in that micro-learning
- no external knowledge requirement
- no trick questions
- no unnecessary complexity
- quiz is NOT a progression gate

### Feedback

Correct:
- brief explanation of WHY the answer is correct

Incorrect:
- show the correct answer
- brief explanation of WHY it is correct

Feedback should be concise, not another lesson.

---

# 5. MODULE POST-TEST

After all micro-learnings in a module:

MICRO-LEARNINGS
→ MODULE POST-TEST

The module post-test:

- evaluates the module as a whole
- may use application/scenario questions
- is a progression/completion gate
- pass threshold = 70%

### Question pool requirement

Do NOT rely on an identical static post-test for every attempt.

Use a question pool and/or meaningful randomization so retakes are not simply memorization of the same answers.

Best-score logic may be retained only when combined with a sufficiently varied assessment pool and sound assessment design.

Module completion:

**All required micro-learning content completed**
AND
**passing post-test score ≥70%**

# 7. KEY DESIGN PRINCIPLES

1. Digital Learning has priority over additional AI breadth.
2. AI supports professional knowledge; it does not replace it.
3. Technology serves learning.
4. Preserve strong existing content where it already satisfies the competency.
5. Prefer KEEP / ENHANCE / MERGE / MOVE / REMOVE / ADD decisions.
6. Avoid engineering creep.
7. Accessibility is part of design, not cosmetic QA.
8. Assess AI through critique and verification, not generation alone.
9. Do not make curriculum dependent on rapidly changing vendor UI.
10. Do not equate completion with learning.
11. Use evidence before major curriculum changes.
12. Keep source evidence, inference, and curriculum recommendation clearly separated.
13. Do not force the 70/30 balance by mechanically counting lessons.
14. Do not lock a final micro-learning count until Level-2 consolidation is complete.
