# AI FUNDAMENTALS — V2 UPDATED SCOPE

## Goal

Build enough AI literacy for a Digital Learning practitioner to understand, question, evaluate, and use AI intelligently.

Target:

**Beginner → Intermediate conceptual literacy**

AI Fundamentals is NOT AI engineering.

---

## MUST UNDERSTAND

### 1. AI Foundations
- What AI is
- AI vs automation
- AI vs machine learning
- relationship between ML and Generative AI
- appropriate vs inappropriate AI use

### 2. Generative AI
- what generative AI is
- how it differs from conventional automation/prediction
- strengths and limitations

### 3. LLM Fundamentals
Understand:
- tokens
- context
- inference
- next-token generation
- probabilistic generation
- why fluent output is not necessarily factual
- context limitations

### 4. Prompting
Practical:
- instructions
- context
- task
- constraints
- examples
- few-shot prompting
- output formats
- decomposition
- iterative refinement
- critique

Prompting is an iterative communication/design skill, not a magic formula.

### 5. Reliability & Verification
Learner should be able to:
- identify unsupported claims
- verify source support
- compare output against source material
- recognize hallucination risk
- identify obvious bias
- recognize automation bias / over-reliance
- decide when SME/human review is required

### 6. Privacy / Security
Understand risks of submitting:
- confidential company information
- proprietary content
- learner PII
- sensitive business information

to public AI systems.

### 7. Responsible AI
Understand:
- human agency
- accountability
- risk-based oversight
- copyright/IP
- responsible use

---

## CONCEPTUAL AWARENESS

Only enough to explain the modern AI ecosystem:

- embeddings
- RAG

For each:

WHAT IT IS
→ WHY IT MATTERS
→ WHAT IT CHANGES FOR A DIGITAL LEARNING PRACTITIONER

Do not teach implementation.

---

## OUT OF CORE

The following are explicitly outside the AI Fundamentals competency:

- neural-network mechanics
- transformer architecture
- attention mechanics
- model training
- advanced fine-tuning
- API development
- vector database engineering
- agent framework engineering
- Python AI development

These may be mentioned briefly only if necessary for conceptual context.

---

## AI FUNDAMENTALS ASSESSMENT

Prefer:
- plain-language explanations
- concept comparisons
- scenario selection
- identifying unreliable output
- source verification
- critique of generated content
- deciding when human review is needed

Avoid:
- vendor-specific trivia
- memorizing architecture terminology
- engineering implementation tasks

Human judgment must be assessed.
