# M19 OBJECTIVE

For every consolidated module:

1. identify learning objectives
2. identify prerequisite relationships
3. identify dependencies
4. group related concepts into coherent micro-learnings
5. target approximately 5 minutes per micro-learning
6. assign exactly one recall question to every micro-learning
7. identify module post-test coverage
8. identify opportunities to KEEP / ENHANCE / MERGE / MOVE / REMOVE / ADD
9. determine the final micro-learning count

Do NOT assume the previous 202/216 estimates are final.

They are obsolete working estimates.
