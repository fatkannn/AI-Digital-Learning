# 1. CORE PHILOSOPHY

## Digital Learning First

The primary professional competency is:

**Digital Learning / E-Learning**

The learner should become capable of:
- identifying learning/performance problems
- designing appropriate learning solutions
- creating digital learning experiences
- selecting and using appropriate learning technologies
- evaluating learning and transfer
- improving learning experiences iteratively

## AI as Enhancement

AI is a modern competency that supports and enhances Digital Learning.

AI must not displace the underlying professional knowledge required to:
- define the learning problem
- make instructional decisions
- evaluate quality
- verify information
- make professional judgments

The curriculum is therefore:

**Digital Learning expertise + AI capability → enhanced Digital Learning practice**

---

# 2. 70/30 DESIGN COMPASS

The approximate 70/30 Digital Learning-to-AI balance is a:

**DESIGN COMPASS, NOT A HARD NUMERICAL REQUIREMENT.**

Do not modify valid curriculum content simply to achieve an exact percentage.

The actual balance is acceptable when:
- Digital Learning remains the primary professional competency
- AI Fundamentals provides necessary AI literacy
- AI Enhancement directly supports Digital Learning workflows
- AI topics have a defensible learning purpose
- AI breadth does not become trend-driven content accumulation

The curriculum should be judged primarily by:
- learning value
- competency coverage
- coherence
- professional relevance
- evidence
- transfer potential

---

# 3. HUMAN-IN-COMMAND

Human-in-Command is a cross-cutting principle.

Core workflow:

**DEFINE → PROMPT → GENERATE → CRITIQUE → VERIFY → DECIDE**

The Digital Learning practitioner remains responsible for:
- defining the problem
- setting quality criteria
- evaluating AI output
- checking evidence
- deciding what to accept, modify, or reject
- professional accountability

AI output is an assistive artifact, not an authority.

---

# 4. CURRICULUM STRUCTURE

The curriculum contains:

**4 phases → 25 modules → 84 micro-learnings → 84 recall questions → 25 module post-tests**

The final count is an architecture baseline.

It may only change through an explicit curriculum review/approval process.

AI-generated content must be:

### Copyright wording

Copyright claims are jurisdiction-specific and must be date-stamped when taught.

For U.S. guidance:
- AI-generated material is not automatically protected merely because a person prompted an AI system
- human authorship and sufficient human creative contribution are important considerations
- significant human modification/creative arrangement may qualify for protection depending on the circumstances

Do not generalize U.S. copyright guidance to every jurisdiction.

# 9. MICRO-LEARNING ARCHITECTURE

Current locked baseline:

**84 micro-learnings**

Target duration:

**approximately 5 minutes**

This is a target, not a timer.

Each microlearning must contain:
1. one coherent learning objective
2. focused explanation/content
3. one clear takeaway
4. exactly one recall question

Do not:
- split concepts unnaturally to increase lesson count
- merge concepts when coherence is damaged
- add content merely to reach five minutes

---

# 10. MICRO-LEARNING RECALL QUIZ

Every microlearning has exactly one recall/retrieval question.

Rules:
- tests explicitly taught content only
- focuses on the key takeaway
- no trick questions
- no external knowledge requirement
- non-gated

Feedback:

### Correct
Brief explanation of WHY the answer is correct.

### Incorrect
Show the correct answer + brief explanation of WHY it is correct.

The recall question is reinforcement, not module mastery.

---

# 11. MODULE POST-TEST

At the end of every module:

**Micro-learnings → Module Post-test**

Post-test:
- assesses the module as a whole
- may use application/scenario questions
- pass threshold = **70%**
- is the module completion gate

Assessment design:
- use question pools and/or meaningful randomization
- avoid identical static tests across every attempt
- ensure retakes are not simple answer memorization

Best-score logic is acceptable only when supported by a sufficiently varied assessment pool and sound retake design.

# 12. EVIDENCE & AUTHORING RULES

## Evidence hierarchy

Prefer:
1. official standards / government / global organizations
2. universities / research institutions / peer-reviewed research
3. established professional organizations
4. reputable industry sources

Distinguish:

**Seminal/reference source**
from
**Free learner-accessible source**

A seminal source does not have to be free if a credible open-access equivalent can be provided for learners.

## Do not overclaim

Avoid absolute statements such as:
- "the only evidence-supported approach"
- "this principle is always true"
- "AI cannot be copyrighted" without jurisdiction/context
- "microlearning is always better"
- "Kirkpatrick is obsolete"

Use appropriately qualified language.

# 16. QUALITY PRINCIPLES

1. Digital Learning remains the primary professional discipline.
2. AI supports rather than replaces professional judgment.
3. Technology serves learning.
4. Preserve strong content where it remains valid.
5. Avoid engineering creep.
6. Accessibility is part of design.
7. Assessment must measure more than completion.
8. AI output must be critiqued and verified.
9. Vendor UI instructions must be resilient to change.
10. Do not equate completion/activity data with learning.
11. Separate evidence, inference, and curriculum recommendation.
12. Avoid unnecessary curriculum expansion.
13. Keep learning objectives measurable and coherent.
14. Do not create lessons merely to satisfy a lesson-count target.
