# M19 — MICRO-LEARNING MAP

Output C of M19 Level-2 Curriculum Consolidation. **This is the most important M19 artifact.**

Design note: every objective in `M19-LEARNING-OBJECTIVE-MAP.md` was written at exactly micro-learning scope (one coherent objective, testable by one recall question), so the map below is a clean **1 objective → 1 micro-learning** ratio throughout. This is a deliberate outcome of Decision Rule 3 (consolidate by learning objective), not a default template — where source material naturally grouped several concepts under one objective (e.g. tokens + probability + next-token prediction under 15.1), that grouping happened during objective-writing, matching the brief's worked example directly. No objective required splitting across multiple micros; none required forcing two objectives into one micro.

Micro ID format: `{module}-{seq}`. Duration is a target, not a timer (Rule 4) — noted range reflects genuine content weight, not a rounding exercise.
